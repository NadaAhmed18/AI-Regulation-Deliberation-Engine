Current Code
Centralized Broadcast Model

Major Missing Elements:
  • No communication graph (all agents hear all messages via DB).

Week 3 Target
Strongly Connected Graph Routing
Agents routed strictly via directed edges (A → B → C → A).
All agents execute each round, perform mid-debate RAG, and update influence deltas.
Week 3 Capabilities:
  • nx.is_strongly_connected(G) == True (Full topological loop).
  • Agent B only digests Agent A's arguments (no broadcast noise).
  • Dynamic mid-discussion retrieval verifies facts during rounds.
  • Influence recorded: |Stance_B - Stance_A| shifts across 3 rounds.

# Routing Rules
1. DO NOT select the agent who just finished speaking.
2. If the previous speaker questioned another panelist, give the floor to that panelist.
3. If a new sub-topic was raised, pick the panelist with matching expertise.
4. If an agent hasn't spoken in a while, prioritize them.
